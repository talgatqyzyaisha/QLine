# QLine
Платформа для онлайн-записи в стоматологию и управления приёмами.


## Регистрация и вход

- `register.html` — регистрация, `login.html` — вход, `auth.js` — логика.
- Демо-версия: пользователи хранятся в браузере (localStorage), пароли — в виде соли и хеша PBKDF2.
- Для рабочего сайта клиники хранение и проверку пользователей нужно перенести на сервер с базой данных.


## Мои записи

- `appointments.html` — страница «Мои записи»: вкладки «Предстоящие», «Прошедшие», «Отменённые», отмена записи.
- `appointments.js` — сохранение и показ записей. Кнопка «Подтвердить» на странице врачей теперь сохраняет запись.
- Демо-версия: записи хранятся в браузере (localStorage). В рабочей версии их нужно хранить на сервере.


## Избранное

- `favorites.html` — раздел «Избранное» (загрузка, ошибка, пустой список, гость), `favorites.js` — логика.
- Сердце на карточке врача (`data-doctor-id`) показывает состояние из хранилища текущего клиента; повторное нажатие убирает врача. Гостю предлагается войти.
- Демо-версия: избранное хранится в localStorage под ключом `favorites_<id клиента>` (без дублей, у каждого клиента свой список).
- Все методы `QLineFavorites` (`list`, `add`, `remove`, `toggle`) возвращают Promise — для рабочей версии их нужно заменить на запросы к серверу и таблицу `favorites(user_id, doctor_id)` с уникальной парой.
